# MikiZip — Just, zip it.

**Download:** https://mist1985.github.io/MikiZipPublic/

MikiZip is a file archiver for macOS, Windows and Linux that checks every archive
before it says done. It makes a standard **.zip** for anyone, a standard **.7z** for
small, and a **MAX (.mkz)** archive for smallest.

This repository hosts the website and the installers
([Releases](https://github.com/mist1985/MikiZipPublic/releases)). MikiZip itself is
closed-source, so its source code is not published here.

| Platform | Installer |
|---|---|
| macOS (Apple silicon) | `MikiZip-<version>.pkg` |
| Windows (64-bit) | `MikiZip-<version>-Setup.exe` |
| Linux x86-64 / ARM64 | `MikiZip-<version>-linux-<arch>.tar.gz` (Python 3.9+) |

The installers are not code-signed. On first launch:
- **macOS:** System Settings → Privacy & Security → **Open Anyway**.
- **Windows:** **More info → Run anyway**.

Each release lists the SHA-256 checksum of every file.
