03 — The rules it never breaks

    
Built so you never lose a file to your archiver.

  

  
    
    
  1. Checked before “done”
    Every archive is read back from disk and compared with your files before MikiZip reports success.
    2. 
    
  2. Nothing overwritten
    Existing files are never replaced unless you say --force, and even then the old one stays intact until the new one is in place.
    3. 
    
  3. Nothing half-written
    Work happens under a private temporary name. Cancel, crash or close the window: only MikiZip’s own temporary files are removed.
    4. 
    
  4. Your originals are read-only
    If a file changes while it is being packed, the job stops instead of saving an inconsistent copy.
    5. 
    
  5. Safe to open anything
    Archives can’t write outside their folder: no ../ tricks, no symlink tricks, no zip bombs. Damage is reported, never guessed at.
    6. 
    
  6. Polite with your machine
    A measured memory budget, low priority, and one CPU core always left free for you.
    7.

06 — Questions

    
Good to know

  

  
Is MikiZip free?
Yes, free to download and use. If it saves you time, you can buy the developer a coffee.

  
Can other people open my archives?
.zip: everyone, with a double-click. .7z: anyone with 7-Zip, WinRAR, Keka or Windows 11. .mkz (MAX) needs MikiZip, so use it for your own archives or when the other person has MikiZip too.

  
Is MAX lossy? Will my photos lose quality?
No. Every file comes back byte for byte identical, and MikiZip proves it by decoding each file and comparing its SHA-256 fingerprint before it finishes.

  
When is MAX not worth it?
On plain text, source code and PNGs it matches 7-Zip rather than beating it, and it is slower to create. It shines on PDFs, JPEG photos and folders of many small, similar files.

  
Is there a window app, or only the terminal?
MikiZip is used from the terminal (mikizip zip, mikizip unzip…). Double-clicking a .mkz file on macOS or Windows opens a small dialog that unpacks it for you.

  
What does MikiZip not keep?
Contents, folders, empty folders, symlinks, permissions and modification times are kept. Extended attributes, Finder tags, ACLs and owners are not, and MikiZip always tells you when a file has any.

  
Does it send anything over the internet?
No. MikiZip works entirely offline.
